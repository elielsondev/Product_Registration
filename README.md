# CRUD de Produtos

## Funcionalidades Principais

- **Cadastro de Produtos:** Permitir o cadastro de produtos com os seguintes campos:
  - Nome
  - Preço
  - Categoria
  - Origem
  - Lote
  - Data de validade
  
- **Listagem:** Exibir todos os produtos cadastrados em uma tabela ou lista estilizada.

- **Edição:** Permitir a edição dos produtos diretamente na lista, atualizando os dados no array.

- **Exclusão:** Permitir a exclusão de produtos, removendo-os do array e da lista exibida.

## Estrutura de Páginas

- **Página inicial** ou menu de navegação.

- **Página de cadastro de produto** (formulário).

- **Página de listagem de produtos**.

## Regras de Implementação

- Todos os dados dos produtos devem ser armazenados em um array no JavaScript.

- A edição deve atualizar o produto diretamente na lista.

- A exclusão deve remover o item da lista e do array.

## Requisitos de Estilo

- Utilizar CSS para tornar o site visualmente agradável, incluindo:

  - Cores harmoniosas

  - Espaçamentos adequados

  - Botões estilizados

  - Efeitos de hover nos elementos interativos
